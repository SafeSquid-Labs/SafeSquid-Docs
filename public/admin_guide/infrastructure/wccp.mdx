<Note>

WCCP works with WCCP routers to redirect traffic to SafeSquid without setting a proxy in each browser.

## Globals / subsections

Enabled; WCCP policies

## Processing

All enabled WCCP policies can be used for router communication.

## Notes

Coordinate service group IDs and passwords with the network team.
