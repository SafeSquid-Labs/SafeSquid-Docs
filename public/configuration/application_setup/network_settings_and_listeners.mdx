---
title: "Network settings"
---

The **Network** section defines client listen sockets and outbound source IP selection for origin connections.

The console splits this section into two tabs, and they are independent of each other: **Listen**
binds the sockets clients connect to, **Interface** picks the source IP SafeSquid uses when it
connects onward.

<Tabs>
  <Tab title="Listen">

    ## Core mechanics

    ### Listen — startup bind

    Every enabled Listen row with `port != -1` binds at startup. If no enabled row matches startup.ini `LISTEN_IP` and `LISTEN_PORT`, an additional fallback bind runs on those defaults. Restart required after Listen changes.

    ## Listen fields

    Open **Configure → Application Setup → Network settings → Listen**.

    <Frame caption="Network settings — Listen rows">
      <img src="/images/configuration/network_settings-listen.webp" alt="SafeSquid console showing Network settings Listen rows including an SSL_TRANSPARENT binding, the Edit Policies icon on the first row circled" />
    </Frame>

    - **IP / Port** — Bind address and client port. Blank IP = dual-stack any when IPv6 available.
    - **Bindings** — `SSL_TRANSPARENT`, `CAPTIVE_PORTAL` implemented; `SSL_AUTHENTICATION` / `SSL_BRIDGE` have no effect.

    ## Examples

    <Tip>

    ### Single proxy port

    **Config:** Listen enabled, blank IP, port 8080.

    **Result:** All interfaces accept on 8080 after restart; Access controls who may connect.
    </Tip>

    ## How to verify

    1. Restart after Listen changes.
    2. `curl -x http://APPLIANCE:8080 http://example.com/`
    3. Enable NETWORK logs; confirm the bind lines.
    4. Match listen socket in Access **Interface** for CONFIG vs PROXY tests.

  </Tab>

  <Tab title="Interface">

    ## Core mechanics

    ### Interface — first match wins

    Outbound walks Interface rows top-down: skip disabled; skip empty Source IP after load; skip when destination is in **Excluded Destination IPs**; require a profile match (connection profiles plus hostname/service tags). The first match picks a source IP from the row's list, keyed by client ID.

    ### Source IP on host only

    Non-local Source IPs are dropped silently at load. If all IPs are dropped, the row is skipped at runtime.

    ```mermaid
    flowchart TB
    outbound[Outbound TCP connect] --> walk[Walk Interface list top-down]
    walk --> gate{"Row disabled, empty Source IP, destination in Excluded Destination IPs, or profile mismatch?"}
    gate -->|Skip| more{More rows?}
    gate -->|Pass| bind["Bind source IP from row's list, keyed by client ID - stop"]
    more -->|Yes| walk
    more -->|No| noBind[No Interface row matched - no bind from this section]
    ```

    ## Interface fields

    Open **Configure → Application Setup → Network settings → Interface**. The live row's outbound
    address field is labeled **IP**, not Source IP as referenced below.

    <Frame caption="Network settings — Interface row">
      <img src="/images/configuration/network_settings-interface.webp" alt="SafeSquid console showing a Network settings Interface row with the ALTERNATE OUTBOUND IP profile, the Edit Policies icon circled" />
    </Frame>

    - **Profiles** — Blank matches all. Typical tag: `ALTERNATE OUTBOUND IP`.
    - **Excluded Destination IPs** — Hyphen ranges; destination in list skips row (CIDR not supported).
    - **Source IP** — Comma-separated local addresses; only host IPs kept; rotated by client id.

    ## Examples

    <Tip>

    ### Excluded destination

    **Config:** Source IP 10.0.0.5, dest\_ips 10.0.0.0-10.255.255.255.

    **Result:** Outbound to 10.x skips row; public destinations may match and bind 10.0.0.5.
    </Tip>

    <Tip>

    ### Source IP not on host

    **Config:** Source IP 198.51.100.99 not assigned to appliance.

    **Result:** IP ignored at load; row skipped — no outbound bind from this row.
    </Tip>

    ## How to verify

    1. Enable NETWORK logs; confirm the `interface_select` lines.
    2. Confirm the chosen source IP on the origin side, not only in the log.

  </Tab>
</Tabs>
