# Files and Folders

SafeSquid server paths hold service controls, module files, policy data, activation material, runtime databases, signature stores, and audit logs. Know these paths before an outage, upgrade, policy dispute, or support escalation so evidence is preserved and changes stay reviewable.

## Quickstart path

1. [Files and Folders](/safesquid_swg/files_and_folders/files_and_folders) - classify server paths by risk, evidence value, and change-control expectation.
2. [Service and Startup Files](/safesquid_swg/files_and_folders/service_and_startup_files) - verify service control, startup behavior, TCP tuning, log rotation, Monit, PAM, and kernel tuning.
3. [Application Binaries and Modules](/safesquid_swg/files_and_folders/application_binaries_and_modules) - identify SafeSquid binaries, add-on modules, feature libraries, section XML, and default startup files.
4. [Policy, Security, and UI Files](/safesquid_swg/files_and_folders/policy_security_and_ui_files) - locate activation files, policy XML, SSL material, SQLite configuration, UI files, CGI scripts, and templates.
5. [Runtime Data and Signatures](/safesquid_swg/files_and_folders/runtime_data_and_signatures) - review temporary files, cache, reporting databases, SSL runtime data, user data, and signature stores.
6. [Logs and Audit Evidence](/safesquid_swg/files_and_folders/logs_and_audit_evidence) - collect configuration, traffic, native, performance, privacy, and process evidence.
