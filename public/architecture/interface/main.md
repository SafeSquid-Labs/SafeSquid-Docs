# Find the Interface Reference You Need

Use this legacy hub for direct access to interface pages that are now surfaced under the Architecture tab sections.

## Quickstart path

1. **[Configuration Portal](/architecture/interface/configuration_portal)** - control policy from the management console.
2. **[Self-Service Portal](/architecture/interface/self_service_portal)** - manage activation and licensing.
3. **[Reporting Service](/architecture/interface/reporting_service)** - investigate incidents with reporting and forensics.
4. **[Supporting Services](/architecture/interface/supporting_services)** - set up the services SafeSquid depends on.
5. **[Supporting Services Monit](/architecture/interface/supporting_services_monit)** - supervise SafeSquid processes with Monit.
6. **[Bind](/architecture/interface/bind)** - run BIND as the local DNS resolver.
7. **[NTP](/architecture/interface/ntp)** - keep system time accurate for authentication, TLS, and log integrity.
