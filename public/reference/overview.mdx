## Required field format

Configuration references will use this structure:

| Field | Required information |
| --- | --- |
| Interface path | Exact navigation path and section |
| Name | Exact UI, file, environment, or API name |
| Purpose | What the setting controls |
| Type and valid values | Boolean, number, string, list, profile, range, or enumerated values |
| Default | Verified default for each supported release |
| Dependencies | Required services, profiles, certificates, licenses, or other settings |
| Security effect | What becomes allowed, denied, inspected, exposed, or recorded |
| Runtime effect | Immediate, new sessions only, reload, restart, or unknown pending validation |
| Evidence | Log, status, output, or behavior that proves the value took effect |
| Failure behavior | Known error or degraded state when invalid or unavailable |
| Version applicability | Release train, exact verified build, introduction, change, and deprecation |
| Related tasks | Procedures that use the field safely |

A blank default is not the same as a verified empty default. Unknown behavior is marked **Pending validation** and is excluded from high-risk production procedures.
