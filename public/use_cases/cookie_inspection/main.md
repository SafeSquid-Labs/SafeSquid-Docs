# Enforce Cookie Policy With Cookie Inspection

Cookies carry tracking and session data across sites.

## Quickstart path

1. **[Cookie Inspection](/use_cases/cookie_inspection/cookie_inspection)** - configure SafeSquid cookie filter to manage, allow, or block cookies for user privacy and policy enforcement.
2. **[Cookie Filter Configuration and Reference](/use_cases/cookie_inspection/cookie_filter_configuration)** - configure and reference SafeSquid cookie filter: Global, Allow, and Deny rules, expiry and profile options, and solution verification.

## Next steps

- **[Header Re-Write](/use_cases/header_rewrite/header_obfuscation)** - configure SafeSquid header filter to allow, deny, or insert HTTP headers for client-server communication control.
- **[Content Modifier](/use_cases/content_modifier/content_modifier)** - configure SafeSquid's Content Modifier to dynamically alter HTML, headers, and data in real-time for security and custom web policies.
