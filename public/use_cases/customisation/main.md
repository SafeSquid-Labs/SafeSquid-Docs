# Apply Customisation to a SafeSquid Node

Custom templates, startup parameters and configuration backups let you tailor how a node looks and starts.

## Quickstart path

1. **[Customisation](/use_cases/customisation/customisation)** - customize SafeSquid's behavior through custom templates for error pages and branding, and startup parameters for performance tuning and operational configuration.
2. **[Configuration Sync](/use_cases/customisation/configuration_sync)** - discover how to enable configuration synchronization across a SafeSquid proxy cluster to ensure consistent policy deployment, reduce administrative overhead, and improve system reliability and security.
3. **[Configure Cloud Restore](/use_cases/customisation/configure_cloud_restore)** - required setup, how Cloud Restore works, and step-by-step configuration to restore SafeSquid configuration and SSL certificates from the cloud.
4. **[Custom Templates](/use_cases/customisation/custom_templates)** - create custom templates in SafeSquid for error pages, branding, and blocked-content replacement using HTML, images, or executables.
5. **[Startup Parameters](/use_cases/customisation/startup_parameters)** - configure SafeSquid startup parameters (LISTEN_IP, MASTER_IP, LOG_LEVEL, threading) for performance and reliability.
