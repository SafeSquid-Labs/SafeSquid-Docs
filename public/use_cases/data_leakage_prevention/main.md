# Stop Sensitive Data With Data Leakage Prevention

Sensitive data that leaves in an upload or a post is hard to take back.

## Quickstart path

1. **[Data Leakage Prevention](/use_cases/data_leakage_prevention/data_leakage_prevention)** - catch data leaks before they become breaches — detect SSN, credit cards, PHI in uploads and block them in real time.
2. **[Content Moderation](/use_cases/data_leakage_prevention/content_analyser)** - combine SafeSquid categorization, text analysis, and image analysis to control inappropriate or risky web content with validation-ready policy design.
3. **[Text Analyzer](/use_cases/data_leakage_prevention/text_analyser)** - use SafeSquid Text Analyzer to score and control web content based on keywords, patterns, and MIME-aware inspection for DLP and content policy enforcement.
4. **[Image Analyzer](/use_cases/data_leakage_prevention/image_analyser_ai)** - use SafeSquid Image Analyzer to inspect images in real time and control risky or policy-violating visual content with profile-aware enforcement.
5. **[Content Fingerprints](/use_cases/data_leakage_prevention/true_mime_fingerprints)** - use SafeSquid content fingerprinting and true MIME detection to identify disguised files, reduce spoofing risk, and improve content-control accuracy.
6. **[External Parser](/use_cases/data_leakage_prevention/adaptable_external_parser)** - use SafeSquid External Parser to send request or response content to a custom program for specialized inspection, transformation, or policy decisions.
7. **[Block Emails or Files including Archives or Social Posts using Keywords](/use_cases/data_leakage_prevention/block_emails_or_files_including_archives_or_social_posts_using_keywords)** - block emails, files, archives, and social posts by keyword in SafeSquid for data leakage protection.
8. **[Block Inappropriate Images by Using Image Analyzer](/use_cases/data_leakage_prevention/block_inappropriate_images_by_using_image_analyzer)** - block inappropriate images in real time with SafeSquid Image Analyzer for safe browsing.
