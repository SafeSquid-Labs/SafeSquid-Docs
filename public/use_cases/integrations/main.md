# Connect SafeSquid Through Integrations

SafeSquid can hand work to other systems instead of doing it all itself.

## Quickstart path

1. **[Integrations](/use_cases/integrations/integrations)** - enterprise integration with VPN for policy enforcement and secure remote access through SafeSquid SWG.
2. **[ICAP Integration](/use_cases/integrations/icap)** - configure ICAP protocol integration in SafeSquid for offloading content scanning to dedicated antivirus and DLP servers for enhanced threat detection.

## Next steps

- **[Malware Scanners](/use_cases/malware_scanning/malware_scanners)** - multi-layer malware detection in SafeSquid using SqScan, ClamAV, ICAP, and adaptable external parsers for threat prevention.
- **[Data Leakage Prevention](/use_cases/data_leakage_prevention/data_leakage_prevention)** - catch data leaks before they become breaches — detect SSN, credit cards, PHI in uploads and block them in real time.
