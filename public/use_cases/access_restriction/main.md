# Enforce Access Restriction Policy

SafeSquid access policies decide web access by identity, destination, time, application and content.

## Quickstart path

1. **[Access Restriction](/use_cases/access_restriction/access_restriction)** - build SafeSquid access policies that make web decisions by identity, destination, time, application, and content so enforcement stays precise and auditable.
2. **[Working of Default Entries in Access Restrictions](/use_cases/access_restriction/working_of_default_entries_in_access_restrictions)** - understand how default SafeSquid access-restriction entries behave so you can modify baseline policy safely without creating hidden enforcement gaps.
3. **[Enforce SafeSearch](/use_cases/access_restriction/safesearch)** - enforce SafeSearch on Google, Yahoo, and Bing through SafeSquid so users cannot disable search-result filtering locally.
4. **[Web Categorization](/use_cases/access_restriction/web_categorization)** - review and refine SafeSquid website categorization so destination-based enforcement stays accurate, explainable, and safe for production use.
5. **[Compliance Templates](/use_cases/access_restriction/compliance_templates)** - pre-configured DLP patterns for PCI-DSS, HIPAA, GDPR, and other regulatory compliance requirements using SafeSquid Text Analyser.
6. **[Access Mobile Applications Through SafeSquid](/use_cases/access_restriction/access_mobile_applications_through_safesquid)** - control mobile app internet access through SafeSquid SWG with proxy enforcement and firewall-aware policies.
7. **[Access Remote Desktop Applications Through SafeSquid](/use_cases/access_restriction/access_remote_desktop_applications_through_safesquid)** - understand how remote desktop applications like AnyDesk, TeamViewer, and AmmyAdmin interact with SafeSquid in different network scenarios and how to effectively block or allow access using HTTPS inspection and access profiles.
8. **[Accessing Business Applications Through SafeSquid](/use_cases/access_restriction/accessing_business_applications_through_safesquid)** - troubleshoot and configure SafeSquid to allow business applications by identifying blocked URLs, authentication issues, and SSL inspection requirements.
9. **[Allow Anydesk](/use_cases/access_restriction/allow_anydesk)** - allow AnyDesk and other remote desktop apps through SafeSquid with user profiles, SSL bypass, and request-type filters.
10. **[Allow Outlook to Work Through SafeSquid](/use_cases/access_restriction/allow_outlook_to_work_through_safesquid)** - configure SafeSquid and firewall rules so Microsoft Outlook works with proxy authentication and SSL inspection enabled.
11. **[Allow Remote Applications to Particular Users](/use_cases/access_restriction/allow_remote_applications_to_particular_users)** - allow specific users to access remote applications via SafeSquid policies, including without application signatures.
12. **[Allow Social Networking Sites During Lunch Hours](/use_cases/access_restriction/allow_social_networking_sites_during_lunch_hours)** - allow social networking access during lunch hours via SafeSquid time profiles while keeping productivity controls.
13. **[Allow Specific YouTube Channel and its Playlist](/use_cases/access_restriction/allow_specific_youtube_channel_and_its_playlist)** - block general YouTube but allow specific channels and playlists in SafeSquid for education.
14. **[Block Specific YouTube Channel](/use_cases/access_restriction/block_specific_youtube_channel)** - block a specific YouTube channel using SafeSquid by creating policies based on Channel-ID and List-ID for targeted video restriction.
15. **[Block Particular User Login to Facebook or Gmail](/use_cases/access_restriction/block_particular_user_login_to_facebook_or_gmail)** - block specific users from logging into Facebook or Gmail via SafeSquid for controlled organizational access.
16. **[Restrict AnyDesk](/use_cases/access_restriction/restrict_anydesk)** - restrict AnyDesk access via SafeSquid policies and proxy configuration for secure network access control.
