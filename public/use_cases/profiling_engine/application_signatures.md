# Application Signatures

You need an active SafeSquid account with at least one activation key. Register at [https://key.safesquid.com/](https://key.safesquid.com/) if needed. Log in to the Self-Service Portal at [https://key.safesquid.com/](https://key.safesquid.com/).

## Adding users using SafeSquid interface for authentication

When no Active Directory (AD) server is available for SafeSquid LDAP, administrators can authenticate users by assigning usernames and passwords via the SafeSquid interface.
