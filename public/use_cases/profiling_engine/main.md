# Build Profiles in the Profiling Engine

Profiles are the building blocks for SafeSquid policies.

## Quickstart path

1. **[Profiling Engine](/use_cases/profiling_engine/profiling_engine)** - stop guessing who's doing what — profile every HTTP request by identity, application, content, and time for Zero Trust web security.
2. **[Application Signatures](/use_cases/profiling_engine/application_signatures)** - add and manage keyword signatures in the Self-Service Portal.
3. **[Request Profiles](/use_cases/profiling_engine/request_profiles)** - use SafeSquid Request Profiles to classify traffic by method, protocol, host, headers, user agent, and request behavior before applying enforcement policies.
4. **[Response Profiles](/use_cases/profiling_engine/response_profiles)** - use SafeSquid Response Profiles to classify downloads and server responses by MIME type, file extension, size, and headers before applying controls.
5. **[Time Profiles](/use_cases/profiling_engine/time_profiles)** - configure SafeSquid Time Profiler to implement time-based internet access control using customizable time ranges including month, day, weekday, hour, and minute.

## Next steps

- **[Access Restriction](/use_cases/access_restriction/access_restriction)** - build SafeSquid access policies that make web decisions by identity, destination, time, application, and content so enforcement stays precise and auditable.
- **[User Groups](/use_cases/authentication/user_groups)** - configure user groups in SafeSquid for group-based web access policies, enabling differentiated security controls for departments, roles, and teams.
