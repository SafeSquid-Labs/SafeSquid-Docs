# Enforce DNS Security Policies

SafeSquid applies DNSBL, GeoIP filtering and homograph detection at the DNS level.

## Quickstart path

1. **[DNS Security](/use_cases/dns_security/dns_security)** - SafeSquid's DNS-level security features including DNSBL, GeoIP filtering, and homograph attack detection.
2. **[Homograph Detection](/use_cases/dns_security/homograph_detection)** - detect and block IDN homograph attacks that use visually similar characters to impersonate legitimate domains.
3. **[DNS Blacklisting](/use_cases/dns_security/dnsbl)** - configure SafeSquid DNSBL to block access to dangerous sites using DNS-based blacklist services.
4. **[Server Geo-Location](/use_cases/dns_security/geoip)** - configure SafeSquid SWG server geo-location profiles to enforce location-aware policies for access control, compliance, and routing optimization.
