# Enforce Policy With URL Redirection

A redirect policy sends a request to a different page instead of blocking it.

## Quickstart path

1. **[URL Redirection](/use_cases/url_redirection/url_redirection)** - configure URL redirection policies in SafeSquid to redirect websites, enforce safe search, and implement content steering for security and compliance.
2. **[Redirect One Website to Another](/use_cases/url_redirection/redirect_one_website_to_another)** - configure SafeSquid to redirect one URL to another using Real Time Content Security Redirect policies.
