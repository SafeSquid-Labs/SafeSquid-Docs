# Compliance Mapper

Use this skill when a page needs credible, bounded compliance framing.

## Goal

Help readers understand which SafeSquid controls support which control objectives and what evidence can support an audit.

## Workflow

1. Start from the technical control and deployment behavior.
2. Map only materially relevant frameworks.
3. Describe the control objective, not just the control ID.
4. State what evidence SafeSquid can provide.
5. State any gaps, assumptions, or non-claims.

## Rules

- Do not imply certification where none exists.
- Do not turn a partial mapping into a compliance guarantee.
- Prefer fewer accurate mappings over many weak ones.
- Keep compliance content embedded in the operational narrative, not as detached fluff.
